## 🛠️ Tech Stack & Architecture

### **Frontend (Client)**
* **Framework**: React 18 (SPA)
* **Build Tool**: Vite (Lightning fast bundling, relative assets, single-file packaging)
* **Styling**: Tailwind CSS (Glassmorphism, dark/light theme, modern gradients)
* **Icons**: Lucide React
* **Hosting**: GitHub Pages with global CDN

### **Backend (Server & APIs)**
* **Runtime**: Node.js (ES Modules)
* **Framework**: Express.js
* **Cloud Hosting**: Render.com (24/7 Cloud Web Service)
* **Email Automation**: Resend HTTPS API (Port 443, instant push notifications)
* **Security & Anti-Spam**: In-memory IP rate limiter, RFC 5322 strict email validator, disposable domain blocklist

### **Database (Cloud)**
* **Provider**: MongoDB Atlas Cloud
* **ORM**: Mongoose 8.x
* **Data Model**: Structured message schema with timestamps, client IP logging, and read status

### **Search Engine Optimization (Google SEO)**
* **Structured Data**: Schema.org `Person` JSON-LD metadata
* **Search Keywords**: Targeted ranking for `Mohit Yadav`, `yadavmohit-sudo`, `KeyPrime Business Solution`
* **Crawlers**: `sitemap.xml`, `robots.txt`, and Google Search Console ownership verification (`google3f272e38d521b234.html`)

## 🚀 Running Locally

### 1. Clone the Repository
```bash
git clone https://github.com/yadavmohit11835-sudo/yadavmohit-sudo.git
cd yadavmohit-sudo
```

### 2. Run Frontend
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Run Backend (Optional)
```bash
cd server
npm install
node server.js
```
The backend will run on [http://localhost:5000](http://localhost:5000).
